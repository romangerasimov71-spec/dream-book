# Формат базы снов (`data/dreams.js`)

```js
window.DREAMS = [
  {
    id: "koshka",                 // латиницей, уникально
    title: "Кошка",               // как показываем
    aliases: ["кот", "котёнок", "кошки", "котята"],  // другие слова и формы, по ним тоже ищем;
                                  // «~замок» — «на выбор»: сон попадает в варианты, но не открывается сразу
                                  // (так «замок» даёт выбор Ключи / Дверь). Без «~» одно слово — только у одного сна
                                  // (проверяет tools/search-cases.js)
    cat: "Животные",              // раздел (см. список ниже)
    mood: "warn",                 // good — к хорошему, warn — к осторожности, mixed — смотря по деталям
    short: "К хитрости рядом — кто-то улыбается, а думает своё.",  // одна фраза, до 90 знаков, для «поделиться» и списка
    text: "3–5 предложений толкования, простым тёплым языком.",
    details: [                    // 2–4 частных случая
      { if: "Ласковая кошка", then: "…" },
      { if: "Кошка царапает", then: "…" }
    ],
    tip: "Совет на день одной фразой."
  }
];
```

Разделы: Животные, Люди и родня, Дом и вещи, Природа и стихии, Еда и напитки,
Тело и здоровье, События и действия, Деньги и работа, Транспорт и дорога,
Праздники и обряды, Страхи и необычное.
