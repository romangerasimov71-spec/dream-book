# Формат базы снов (`data/dreams.js`)

```js
window.DREAMS = [
  {
    id: "koshka",                 // латиницей, уникально
    title: "Кошка",               // как показываем
    aliases: ["кот", "котёнок", "кошки", "котята"],  // другие слова и формы, по ним тоже ищем;
                                  // «~замок» — «на выбор»: сон попадает в варианты, но не открывается сразу
                                  // (так «замок» даёт выбор Ключи / Дверь). Без «~» одно слово — только у одного сна
                                  // (проверяет tools/search-cases.js)
    cat: "Животные",              // раздел (см. список ниже)
    mood: "warn",                 // good — к хорошему, warn — к осторожности, mixed — смотря по деталям
    short: "К хитрости рядом — кто-то улыбается, а думает своё.",  // одна фраза, до 90 знаков, для «поделиться» и списка
    text: "3–5 предложений толкования, простым тёплым языком.",
    details: [                    // 2–4 частных случая
      { if: "Ласковая кошка", then: "…" },
      { if: "Кошка царапает", then: "…" }
    ],
    tip: "Совет на день одной фразой."
  }
];
```

Разделы: Животные, Люди и родня, Дом и вещи, Природа и стихии, Еда и напитки,
Тело и здоровье, События и действия, Деньги и работа, Транспорт и дорога,
Праздники и обряды, Страхи и необычное.

# Формат предсказаний (`data/predictions.js`) — «Мой сонник на неделю»

```js
window.PREDICTIONS = [
  {
    id: "p001",          // латиницей, уникально
    mood: "good",        // good — хороший день, mixed — с хлопотами, но к добру, warn — «будьте внимательнее»
    text: "Хороший день для разговора, который вы давно откладываете: …",  // без слова «сегодня» и без дней недели
    tip: "Начните с тёплого слова — дальше пойдёт легче."                  // совет одной фразой
  }
];
```

Как выбирается предсказание (`app.js`, `predictionFor`): при первом запуске приложение создаёт
своё случайное число (`sonnik_seed`, хранится как «недавно смотрели»; никаких данных площадки).
По нему все предсказания выстраиваются в личный круг; предсказание на дату — место в круге по
номеру дня. Поэтому: тот же человек и тот же день → то же предсказание; 7 дней подряд → 7 разных;
`warn` стоят в круге не ближе 7 мест друг к другу → за любые 7 дней не больше одного.
Чтобы это держалось, `warn` должно быть не больше 1/7 от всех (сейчас 5 из 100); лишние `warn`
в круг не попадут. Нужно минимум 7 предсказаний, иначе «неделя» не показывается.
Файл необязательный: без него приложение работает, «недели» нет.
