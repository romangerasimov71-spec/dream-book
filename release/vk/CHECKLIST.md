# Выкладка «Сонника» в ВК и ОК — чек-лист

Порядок и подводные камни — `game-studio/docs/PUBLISH.md`, раздел 2. Playgama не трогаем, язык только русский.
Адрес приложения (хостинг): https://romangerasimov71-spec.github.io/dream-book/ (проверен, открывается).
Кабинет — **dev.vk.ru** (не .com). Если не открывается — VPN Happ, профиль «ВК напрямую».

## Что лежит рядом
- `texts.md` — название, слоган, описания, категория, возраст, ключевые слова.
- `icons/icon-576.png` (+278, 150, 75), `favicon-32.png`, `snippet-1120x630.png`.
- `screens/1…6-*.png` — 600×1200, книжные.
- Исходники: `tools/release-art.js` (картинки), `tools/release-shots.js` (скриншоты).

## Открытый вопрос до начала
Сонник — не игра. В кабинете ВК при создании выбрать тип **«Мини-приложение»** (если такого выбора нет — «Игра»).
Размеры картинок для мини-приложений могут отличаться от игровых; подготовлены по PUBLISH.md (иконка 576, фавикон 32, сниппет 1120×630, скриншоты 600×1200).
В кабинете смотреть подсказки размеров рядом с полями; если просит другое — переделать `tools/release-art.js` за минуты.
Для ОК приложение идёт той же заявкой ВК+ОК. Проверить, что «Развлечения/Гороскопы» есть среди категорий ОК.

## Что сделают Костя / бригадир через браузер на Маке
1. Создание приложения: `dev.vk.ru/ru/admin/create-app`, тип «Мини-приложение» (или «Игра»), название из texts.md.
   ⛔ Подтверждение — только Роман (см. ниже). Записать ID.
2. Информация: описание, краткое описание, слоган, Company Name — из texts.md. Сохранить.
3. Размещение: состояние «Включено»; URL для мобильного приложения, Web и мобильной версии — ссылка GitHub Pages. Сохранить. Проверить `vk.ru/app<ID>`.
4. Отображение: Книжная, кнопки «Над окном», адаптация под iPhone «Отключена». Сохранить.
5. Оформление: иконка 576, фавикон 32, сниппет 1120×630, скриншоты (переключить «Книжная», 600×1200; по одному, после каждого перезагрузить страницу; минимум 3, загружаем 6). Файлы в страницу — fetch с raw.githubusercontent.com → File → DataTransfer.
6. Правовые документы: «Использовать типовые документы».
7. **Вписать адреса в `config.js`** (без этого ссылки «поделиться» поведут на GitHub Pages):
   - `APP_URL.vk = "https://vk.com/app<ID>"`
   - `APP_URL.ok = "https://ok.ru/game/<ID ОК>"` (адрес ОК показывает кабинет после привязки)
   Поднять `version` (например 1.0.1), commit + push в `main`, дождаться обновления GitHub Pages, проверить, что в окне «Поделиться» ссылка ведёт на ВК/ОК.
8. Другие площадки → ОК → «Опубликовать» (⛔ Роман).
9. Модерация: все пункты зелёные → одна заявка, площадки ВКонтакте и Одноклассники (Костя подаёт заявку: это входит в «выкладывай»).
10. После одобрения — «Монетизация» → включить рекламу (реклама за награду «неделя» и баннер).
11. `STATUS.md`, карточка на доске, лента; commit + push.
