# Сонник — мини-приложение для ВК и ОК

Это **не игра**, а мини-приложение. Правила студии (порядок работы) — в
`romangerasimov71-spec/game-studio/CLAUDE.md`. Здесь — решения по самому приложению.

## Что это
Человек вводит слово из сна — получает толкование. Плюс «сон дня» и кнопка
«поделиться». Аудитория — в первую очередь Одноклассники (старше 40),
значит: крупный шрифт, контраст, простые слова, никаких мелких кнопок.

## Устройство
- `index.html`, `style.css`, `app.js` — приложение без движка. `index.html` сначала запускает
  Playgama Bridge (`platform.js`), потом грузит базу, поиск и `app.js`.
- `data/dreams.js` — база снов (`window.DREAMS = [...]`), формат — в `docs/DATA.md`; `search.js` — поиск.
- `data/predictions.js` — 100 предсказаний на день для «Моего сонника на неделю» (формат и правило
  выбора — `docs/DATA.md`). Грузится после базы снов; нет файла — нет недели, остальное работает.
  Неделя открыта: экран `#week` — «Сегодня» + 7 следующих дней (дата, настроение, текст, совет,
  строка «Сон дня в этот день», «Поделиться»), внизу «Поделиться неделей» (даты и целые первые
  предложения 2–3 дней); на главной — «Ваше предсказание на сегодня». Экран сам обновляется в полночь.
  Закрыта: объяснение + пример (завтра: первые слова, остальное под замком) + кнопка рекламы.
- `config.js` — настройки в одном месте: версия сборки, адреса приложения во ВК/ОК (`APP_URL`,
  для ссылок «поделиться»), место под баннер, сколько ждать рекламу, на сколько дней неделя.
- `platform.js` — вся площадочная часть (общий шаблон мини-приложений студии, без логики сонника):
  Bridge, `game_ready`, хранилище (Bridge, запасное — localStorage), реклама за награду,
  баннер, «поделиться» средствами ВК/ОК, буфер обмена. Имитация рекламы и полоски баннера —
  только на проверочных адресах (*.github.io, localhost, 127.0.0.1, файл): `?fakead=cancel|fail|silent|late`,
  `?fakeadsec=1`, `?nobanner`. На любом другом адресе без Bridge рекламы и недели нет.
  Опоздавшая реклама (началась после «не загрузилась»), досмотренная до конца, даёт неделю.
- `analytics.js` — отметки для статистики через Bridge (общий шаблон); список — `docs/analytics.md`.
- `playgama-bridge.js` (Bridge 2.4.1, как в «Новогодней сортировке») и `playgama-bridge-config.json`
  (места рекламы: rewarded `week`, баннер `bottom`) — рядом с `index.html`.
- Сохраняется: `sonnik_recent` («Недавно смотрели»), `sonnik_week` (`{from: номер дня}` — когда
  открыта неделя; держится 7 дней, включая день открытия), `sonnik_seed` (своё случайное число
  для личных предсказаний, создаётся при первом запуске).
- Проверки: `tools/check.js` (экраны, поиск, поделиться), `tools/search-cases.js` (поиск на базе),
  `tools/check-platform.js` (баннер, неделя за рекламу, хранилище, ВК/ОК, статистика),
  `tools/ads-test/` + `tools/ads-adapter.js` (набор проверки рекламы студии; запуск — в адаптере).
  Запуск: `NODE_PATH=/opt/node-tools/node_modules node tools/<файл>.js`.
